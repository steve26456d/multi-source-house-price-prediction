## 一、评估目标

本项目的评估部分需要回答以下问题：

1. 单模态模型中，结构化特征和文本特征分别能达到什么预测效果？
2. 多模态融合模型是否优于单模态基线？
3. 早期融合、中期融合、晚期融合三类策略中，哪一种更稳定、更有效？
4. 融合模型的提升是否具有统计显著性？
5. 模型在哪些样本或价格区间上误差较大？

因此，评估指标既要覆盖整体误差，也要能支持后续的消融实验、显著性检验和错误分析。

---

## 二、核心指标

### 2.1 RMSE

RMSE（Root Mean Squared Error，均方根误差）是本项目的核心指标。

公式：

```text
RMSE = sqrt(1/n * Σ(y_i - ŷ_i)^2)
```

其中：

- `y_i` 表示真实房价
- `ŷ_i` 表示预测房价
- `n` 表示样本数量

解释：

- RMSE 与房价单位相同，便于解释模型平均预测偏差。
- RMSE 对大误差更敏感，适合发现模型在高价房、异常样本上的明显失败。
- 本项目模型排序优先参考 test split 上的 RMSE。

注意：

- 如果房价分布长尾明显，RMSE 可能被少量高价样本强烈影响。
- 建议结合 MAE 和分价格区间误差一起解释。

---

### 2.2 MAE

MAE（Mean Absolute Error，平均绝对误差）用于衡量平均绝对预测偏差。

公式：

```text
MAE = 1/n * Σ|y_i - ŷ_i|
```

解释：

- MAE 与房价单位相同，直观表示模型平均差多少钱。
- 相比 RMSE，MAE 对极端误差不那么敏感。
- 当 RMSE 明显高于 MAE 时，说明模型可能存在少量大误差样本。

使用方式：

- 与 RMSE 一起判断误差分布是否稳定。
- 用于报告中解释模型的平均业务误差。

---

### 2.3 R²

R² Score（决定系数）用于衡量模型对房价方差的解释程度。

公式：

```text
R² = 1 - Σ(y_i - ŷ_i)^2 / Σ(y_i - mean(y))^2
```

解释：

- R² 越接近 1，说明模型解释能力越强。
- R² 等于 0 表示模型效果相当于直接预测平均房价。
- R² 小于 0 表示模型甚至差于均值预测。

使用方式：

- 用作辅助指标，帮助解释模型整体拟合能力。
- 不建议单独作为最终排序依据，因为在长尾价格分布下可能不够直观。

---

### 2.4 MAPE

MAPE（Mean Absolute Percentage Error，平均绝对百分比误差）用于衡量相对误差。

公式：

```text
MAPE = 1/n * Σ |(y_i - ŷ_i) / y_i| * 100%
```

解释：

- MAPE 表示平均相对误差比例。
- 适合比较不同价格区间中的相对预测偏差。
- 在房价预测场景中，MAPE 能帮助判断模型误差是否具有实际可接受性。

注意：

- 当真实值接近 0 时，MAPE 会不稳定。
- 房价通常为正且远离 0，因此本项目可以使用 MAPE。
- 如数据中存在异常低价或 0 价格样本，应先过滤或单独说明。

## 三、指标优先级

本项目建议采用以下优先级解释模型表现：

| 优先级 | 指标 | 作用 |
|--------|------|------|
| 1 | RMSE | 主要排序指标，关注整体误差和大误差惩罚 |
| 2 | MAE | 辅助解释平均绝对偏差 |
| 3 | R² | 辅助解释模型整体拟合能力 |
| 4 | MAPE | 辅助解释相对误差和业务可接受性 |

模型最终结论不应只依赖单一指标。若某个模型 RMSE 最低但 MAE、MAPE 表现较差，需要结合残差图和错误分析判断其稳定性。

---

## 四、数据划分上的评估原则

所有模型必须在同一数据划分上评估，避免结果不可比。

建议划分方式：

| 数据集 | 划分方式 | 说明 |
|--------|----------|------|
| Ames | 随机划分 | 样本规模较小，主要用于结构化基线 |
| Florida | 时间顺序划分 | 更接近真实预测场景，避免未来信息泄露 |

每个模型至少记录以下 split 上的指标：

- train
- val
- test

最终报告重点展示 test split 指标，val split 用于模型选择和调参说明。

## 五、实验记录字段

实验结果建议统一保存为 CSV，字段如下：

| 字段 | 类型 | 说明 |
|------|------|------|
| `experiment_id` | str | 实验唯一编号 |
| `model_name` | str | 模型名称 |
| `modality` | str | 模态类型 |
| `split` | str | train / val / test |
| `rmse` | float | 均方根误差 |
| `mae` | float | 平均绝对误差 |
| `r2` | float | 决定系数 |
| `mape` | float | 平均绝对百分比误差 |
| `params` | str | 超参数 JSON 字符串 |
| `timestamp` | str | 实验时间戳 |

`modality` 建议取值：

- `structured`
- `text`
- `fusion_early`
- `fusion_mid`
- `fusion_late`

---

## 六、预测结果保存字段

为支持可视化、显著性检验和错误分析，建议每个模型保存逐样本预测结果：

```text
sample_id,y_true,y_pred,split,model_name,modality
```

如后续需要分析价格区间、文本长度或地区因素，可扩展字段：

```text
price_bin,text_length,city,property_type,error,abs_error,ape
```

其中：

- `error = y_pred - y_true`
- `abs_error = |y_pred - y_true|`
- `ape = |y_pred - y_true| / y_true`

---

## 七、报告中的解释方式

最终报告中建议按以下顺序解释指标：

1. 先展示所有模型在 test split 上的 RMSE、MAE、R²、MAPE 总表。
2. 再比较最佳单模态模型与最佳融合模型，说明融合是否带来提升。
3. 用消融实验说明文本模态的增量贡献。
4. 用显著性检验证明提升是否可靠。
5. 用错误分析解释模型仍然失败的场景。

推荐表述模板：

```text
从 RMSE 和 MAE 看，融合模型相较结构化基线在整体误差上有所下降；
从 R² 看，融合模型对房价方差的解释能力更强；
从 MAPE 看，融合模型在相对误差层面也更稳定。
结合消融实验可知，文本模态对房价预测提供了额外信息。
```
