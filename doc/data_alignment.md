## 一、两个数据源的模态分析

| 数据源 | 样本数 | 字段数 | 结构化特征 | 文本特征 | 标签 |
|--------|--------|--------|----------|----------|------|
| Ames Housing | 2930 | 82 | ✅ | ❌ | SalePrice |
| Florida Sold 2026 | 10893 | 14 | ✅ | ✅ sanitized_text | lastSoldPrice |

本项目使用两个数据集进行房价预测实验。其中，Ames Housing数据集主要用于构建结构化特征基线模型；Florida Sold 2026数据集同时包含结构化字段和文本描述，是后续多源数据融合实验的核心数据集。
根据第13周数据的探索结果，Ames Housing数据集包含2930条房屋销售记录和82个字段；Florida Sold 2026数据集包含10893条房产成交记录和14个字段。

## 二、对齐策略

### 2.1 Florida 数据集内部对齐（主要实验数据）

Florida 数据集的每条记录天然包含结构化特征与文本描述，**无需额外对齐**。
实际数据字段中，Florida数据集没有单独的唯一ID字段，因此本项目采用**DataFrame行索引**作为记录级对其依据。每一行样本同时对应：
- 结构化特征；
- 文本描述字段；
- 目标变量。

其中，文本字段为：sanitized_text。
该字段是经过脱敏和清洗后的房源描述文本，可用于后续TF-IDF、BERT等文本特征提取。

Florida数据集中的主要结构化特征包括：
- type
- sub_type
- listPrice
- sqft
- stories
- beds
- baths
- baths_full
- baths_full_calc
- garage
- year_built
- zip
  
目标变量为：lastSoldPrice。因此，Florida数据集内部采用记录集对齐方式：
```
Florida Record 
├── Structured Features 
│ ├── type 
│ ├── sub_type 
│ ├── listPrice 
│ ├── sqft 
│ ├── stories 
│ ├── beds 
│ ├── baths 
│ ├── garage 
│ ├── year_built 
│ └── zip 
├── Text Feature 
│ └── sanitized_text
├── Target Label
│ └── lastSoldPrice
```
因此，在后续特征工程阶段，只需要保证结构化特征矩阵、文本特征矩阵和目标变量按照相同样本顺序生成，即可完成多模态数据对齐。

### 2.2 Ames 数据集的角色

Ames 数据集仅作为**结构化特征的独立基准**：
- 训练纯结构化模型（Random Forest / XGBoost）以建立性能上界参考
- 不参与多模态融合实验（因其缺乏文本数据）
- 可用于验证结构化特征工程的通用性

Ames数据集中的目标变量为SalePrice。根据初步EDA，该数据集的房价分布呈明显右偏特征，少量高价房形成长尾分布。结构化特征中，Overall Qual、Gr Liv Area、Garage Cars、Garage Area、Total Bsmt SF 等字段与房价具有较强相关性。

## 三、数据划分方案

### 3.1 Florida 数据集（随机划分）

原计划采用时序划分方式，即按照成交时间排序后进行训练集、验证集和测试集划分。
但根据当前下载并验证的数据字段，Florida 数据集中未提供明确的 sold_date 或成交日期字段，因此当前阶段无法进行严格的时序划分。

因此，Florida 数据集暂采用随机划分方式：
```
随机划分（random_state=42） ：
├── 训练集：80% 
├── 验证集：10% 
└── 测试集：10% 
```

**原因**：当前数据集中缺少明确的成交日期字段，无法按照时间窗口进行排序。后续如果补充到成交日期字段，可进一步调整为时序划分方式，以更接近真实房价预测场景，并减少时间泄漏风险。

### 3.2 Ames 数据集（随机划分）

Ames 数据集作为结构化基线数据集，同样采用随机划分方式：
```
随机划分（random_state=42）：
├── 训练集：80%
├── 验证集：10%
└── 测试集：10%
```
随机划分可以保证训练集、验证集和测试集中的样本分布相对一致，适合作为结构化基线模型的实验划分方式。

## 五、目标变量分析

| 数据源 | 目标列 | 典型范围 | 分布特征 |
|--------|--------|----------|----------|
| Ames Housing | SalePrice | 约 12k - 755k | 明显右偏，存在少量高价长尾样本 |
| Florida Sold 2026 | lastSoldPrice | 约10–51.7M | 极度右偏，存在超长尾高价房产样本 |

### 5.1 Ames Housing 目标变量分析

Ames Housing 数据集中的目标变量为 SalePrice。

根据初步 EDA，SalePrice 的分布呈明显右偏特征。多数房屋价格集中在中低价格区间，少量高价房形成长尾分布。

这种分布特征说明，后续建模阶段可以考虑对目标变量进行对数变换，例如：

```
log(SalePrice)
```

对数变换可以缓解目标变量偏态分布对模型训练的影响，使模型更加关注相对价格差异，而不是被少量高价异常样本主导。

### 5.2 Florida Sold 2026 目标变量分析

Florida Sold 2026 数据集中的目标变量为：

```
lastSoldPrice
```

根据EDA结果，该字段无缺失值，可以直接作为预测标签使用。

描述性统计结果如下：

| 指标 | 数值 |
|--------|--------|
| 样本数 | 10893 |
| 平均值 | 557,974 |
| 中位数 | 365,000 |
| 25%分位数 | 255,000 |
| 75%分位数 | 557,500 |
| 最小值 | 10 |
| 最大值 | 51,667,180 |
| 偏度 | 19.89 |

从价格分布图可以看出，lastSoldPrice 呈现极明显的右偏分布。

大量样本集中在中低价格区间，而少量高价值豪宅形成超长尾结构。平均值显著高于中位数，进一步验证了数据分布存在较强偏态。

因此，在后续建模阶段将重点评估目标变量对数变换的效果：

log(lastSoldPrice)

通过对数变换可以降低极端高价样本对模型训练的影响，提高模型稳定性和泛化能力。

从相关性分析结果可以看出，房屋整体质量、地上居住面积、车库容量、车库面积、地下室面积和一楼面积等变量与房价之间具有较强正相关关系。

其中，Overall Qual 与 SalePrice 的相关系数最高，说明房屋整体质量是影响房价的重要因素。Gr Liv Area、Total Bsmt SF 和 1st Flr SF 等面积类变量也与房价密切相关，说明房屋使用空间越大，价格通常越高。

### 6.2 相关性分析的作用

结构化特征相关性分析主要用于：

- 理解不同字段与目标变量之间的关系；
- 辅助选择重要结构化特征；
- 为后续模型解释提供依据；
- 为 Florida 数据集的结构化建模提供参考；
- 检查特征工程结果是否符合房地产价格预测的一般规律。

需要注意的是，相关系数只能反映线性关系，不能完全代表模型中的非线性影响。因此，在后续建模阶段，还需要结合树模型特征重要性、SHAP 值等方法进一步分析特征贡献。

## 七、文本数据分析

### 7.1 Florida 文本字段概况

Florida Sold 2026 数据集中的文本字段为：

```
sanitized_text
```

该字段是经过脱敏处理后的房源描述文本。根据初步 EDA，文本长度统计结果如下：

| 指标 | 数值 |
|--------|--------|
| 样本数 | 10893 |
| 平均文本长度 | 1191.82 |
| 标准差 | 684.64 |
| 最小值 | 0 |
| 25% 分位数 | 722 |
| 中位数 | 1014 |
| 75% 分位数 | 1557 |
| 最大值 | 4010 |

从文本长度分布可以看出，Florida 数据集中的房源描述文本整体较为丰富。大部分文本长度集中在 700 到 1600 个字符之间，说明多数样本包含较完整的房源描述信息。

### 7.2 文本内容的潜在价值

Florida 数据集中的房源描述文本通常包含以下信息：

- 房屋装修与维护情况；
- 房间布局与空间特点；
- 社区环境与周边配套；
- 地理位置与交通条件；
- 景观优势及特殊卖点。

这些信息难以完全通过结构化字段表示。例如，结构化字段能够记录房屋面积、卧室数量和建造年份，但无法准确描述装修质量、社区吸引力以及房屋特色。

因此，sanitized_text 字段具有潜在的预测价值，可以为房价预测模型提供额外信息。后续文本特征工程将基于 sanitized_text 字段进行：

- TF-IDF 特征提取；
- TruncatedSVD 降维；
- BERT 或轻量级预训练语言模型嵌入提取。
